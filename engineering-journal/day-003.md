# Day 3 - Python Data Types and Type Conversion

## What I Learned

- Learned Python primitive data types.
- Understood that variables refer to objects.
- Learned the purpose of type(), isinstance(), int(), float(), str(), and bool().
- Learned explicit type conversion creates a new object.
- Learned truthy and falsy objects.
- Learned how to read a Python traceback.
- Understood ValueError and why it occurs.

## Mistakes I Made

- Thought Python performs intermediate conversions automatically.
- Thought int("25.5") would return 25.
- Confused direct object conversion with multiple-step conversion.

## What I Improved

- I now think in terms of variables referring to objects.
- I can predict the result of most type conversions.
- I can identify when a conversion is valid or raises a ValueError.

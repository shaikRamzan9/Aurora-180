# VARIABLES 

# Variable naming rules
  1. variable must start with an alphabet or underscore
  2. it should not start with numbers
  3. it should not have special characters
  4. no space should given between variables
  5. Python keywords cannot be used as variable name.


# Dynamic Typing
Python will allow the Dynamic Typing like it automatically updates the object.
ex: x = 100
x =12.3
here initially x is 100 but by dynamic typing x is updated as 12.3 float vaue

# multiple assignment 

As python allows dynamic typing it also allows multiple assignment at a single time in one line of code 

ex:

here a,b,c are three different variables which refers to the  three differnet objects  of interger values 10,20,30
